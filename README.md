One line, at most 200 characters, about a small good thing that happened today — written for the [Make the Judge Smile](https://make.fun/bounty/u-gentle-badger-68-make-the-judge-smile-9228676d) bounty on [make.fun](https://make.fun).

## The entry

> This morning the neighbour's cat stole my warm chair, fell asleep on my keyboard, and for once I let the deadline wait — judge, even you have to smile at that.

159 characters. A small good thing, told warm, specific, and with a little surprise — and it talks to the judge, which the bounty allows.

## How it works

`main.ts` (Node 22, no dependencies) validates the line against the gate — 1–200 characters, not only white space, a single line — then writes it to `/output/entry.txt` with no trailing newline, and reads the file back to verify it is byte-for-byte the validated line.

## Run

```sh
node main.ts
```
